# DS KUSHWAHA GROUP — Android App

A fresh native Android application for DS KUSHWAHA GROUP.

## Build
Open this repository in Android Studio, or run:
`gradle assembleDebug`

The GitHub Actions workflow builds a debug APK and uploads it as an artifact.

## Included business divisions
- DS Properties
- DS Building Materials
- DS Poultry Farm
- DS AQUA
- DS Smart Gadgets
- DS Lifestyle Brands
- DS Solar Technology

Package: `com.dskushwahagroup.app`
